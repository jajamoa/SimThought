# Simulating Society Requires Simulating Thought

Position paper, NeurIPS 2025 Position Paper Track. [Paper (arXiv 2506.06958)](https://arxiv.org/abs/2506.06958) · [Project page](https://jajamoa.github.io/SimThought/)

Social simulation with LLMs must move from a behaviorist "demographics in, behavior out" paradigm to cognitively grounded reasoning that is structured, revisable, and traceable. The paper introduces Generative Minds (GenMinds), a conceptual modeling paradigm, and RECAP, a framework for evaluating reasoning fidelity.

`docs/` holds the project page (GitHub Pages).
